## 2. 구조

```
vica-base.target   display · lidar · app · web · supervisor · container → d455 · imu
                   safety → motor (nice −10, UDP 전용) · mode (UDP 전용)
vica-drive.target  nav2(bond 8 s) · posecheck · mission · handle · monitor   ← 모드 노드가 켜고 끈다
```

**모드 노드** `scripts/autostart/vica_mode_node.py` (판정은 `mode_logic.py`, 상태를 저장하지 않는다)

| 이름 | 종류 | 하는 일 |
| --- | --- | --- |
| `/vica/mode/drive_start` | Trigger | 주행 묶음 켜기. 지도 그리기 중·칸에서 띄운 주행 노드·can1 DOWN·중복이면 거부. 정지 예약 중이면 예약 취소 |
| `/vica/mode/drive_stop` | Trigger | 끄기. 움직이는 중이면 거부. Nav2 가 뜨는 중이면 예약(늦어도 45 s) |
| `/vica/mode/nav2_restart` | Trigger | Nav2 유닛만 다시 띄우기(사람용, 기동 실패 뒤) |
| `/vica/mode_status` | String JSON, 2 s, TRANSIENT_LOCAL | `mode` idle·drive·mapping · `state` idle·starting·need_initial_pose·running·stopping·error · `detail` · `nav2` · `safety` · `reset_needed` · `failed_units` · `missing_nodes` · `duplicated` · `stop_timeouts` · `stop_in_sec` |

- Nav2 단계는 이번 호출의 저널에서 읽는다: navigation·localization 관리자의 `Failed to bring up` = 중단,
  amcl `Please set the initial pose` = 초기 위치 대기, navigation `Managed nodes are active` = active.
  collision_monitor 관리자는 launch 의 12초 재시도 때 늘 중단 줄을 남겨 뺀다.
- 주행 묶음 target 은 소속 유닛이 다 뜰 때까지 inactive 다(systemd 가 Wants 에 After 를 붙인다).
  켜짐 판정은 소속 유닛까지 본다(`drive_on`).
- 실행 스크립트(전 유닛): 준비 중 정지 신호가 오면 명령을 띄우지 않는다. 우선순위는 스크립트의
  `renice`로 올린다 — 유닛 `Nice=` 는 권한이 없으면 유닛이 아예 안 뜬다.
- nice 한도는 `/etc/security/limits.d/vica-nice.conf`(`ji_w - nice -10`, install.sh 4단계). user@.service 의
  `LimitNICE=` 는 관리자를 띄우는 PAM(`pam_limits`)이 0 으로 덮어 효과가 없었다(12:37 재부팅 확인).

## 5. 실기에서만 나온 것

- **측정 도구가 결과를 바꾼다.** nice 0·공유메모리 측정 도구는 기동 중 자기가 밀려 몰아서 받았다
  (p99 209 ms, 실제 safety 는 제때). 모터와 같은 UDP 전용·nice −10 으로 재야 한다.
- **준비 중 정지 신호 유실.** bash 는 신호를 처리하고 정상 종료한 하위 프로세스를 보면 다음 줄로 간다.
  감시 유닛이 16:03:35.49 정지 신호 뒤 36.14 에 ros2 launch 를 띄워 20 s 시한 초과로 SIGKILL 됐다.
- **13:34~13:45 (앞 부팅) 정지 61~72 s.** 위치 확인 20 s·Nav2 30 s 시한 초과가 5/5. `fastdds shm clean`
  으로 안 풀리고 재부팅으로 풀렸다. 그 뒤 33회에 재현 안 됨 — 원인 미확정.
- **앱 경로 `/robot_status` 0건.** 13:57 부팅 그대로의 앱 유닛에서 50 s 동안 안 왔고, 재기동(UDP) 뒤 1.8 Hz.
