# 병원 촬영 — 매핑·목적지 등록 절차

작성 2026-09-03, **갱신 2026-10-07**(앱이 멘트를 만들지 않음, 입구 방향·대기 장소 추가).
코드 변경 없이 **지금 있는 기능만으로** 병원 시나리오를 준비하는 순서다. 학교 촬영(배달 모드 계획서 `docs/superpowers/plans/2026-09-02-delivery-mode-video.md`)과는
별개다.

원칙 한 줄 — **좌표와 id 는 앱이, 글자는 손이.** 좌표는 지도 클릭 실측값이라
손으로 못 만들고, id 는 UUID v4 가 아니면 미션이 파일 전체를 거부한다
(`vica_mission_manager/destinations.py`). 별칭·유형은 파일에서 고치는 편이 빠르다.
멘트(확인·도착)는 **비워 둔다** — 코드가 조사까지 맞춰 채운다(3절).

## 0. 전제

- 젯슨 실기. 브랜치는 무관(어느 브랜치든 같은 절차).
- 지도는 **새로** 만든다. 옛 지도 목적지(화장실2·방1…)는 쓰지 않는다.
- 병원 복도는 길다 — 9/3 학교 복도 매핑에서 앞뒤 미끄러짐(1 m 초과 48~59 %)이
  나왔다. 아래 1절의 주의를 지킨다.

## 1. 매핑 (앱 SLAM 모드)

1. imu 노드를 띄운 뒤 **로봇을 20초 이상 완전히 세워 둔다** — 자이로 바이어스
   보정(50 Hz × 1000샘플). 이걸 빼먹으면 회전이 밀린다.
2. 앱 SLAM 모드로 매핑 시작. 지도 id 는 날짜·장소로(예: `vica_map_0905_hosp`).
   **이름은 나중에 `.env`·launch 인자에 그대로 쓴다.**
3. 천천히 — 키보드 teleop 칸은 기본 0.5 m/s · 1.0 rad/s 로 뜬다. 앱 teleop(0.3/0.4)
   이 더 안전하다. 긴 복도는 벽 가까이, 교차로·문 앞에서 멈춰 한 바퀴.
4. 가능하면 `scripts/vica_map_record.sh` 로 bag 을 남긴다 — 미끄러짐이 나오면
   오프라인 재계산으로 살릴 수 있다.
5. 앱에서 **지도 저장**. 저장 뒤 `~/vica_data/destinations/<지도id>/` 폴더가
   생기는지 본다(첫 목적지 저장 때 만들어진다).

## 1.5 레일 — 연습장 레일을 홈 기준으로 그대로 찍기 (2026-10-10 추가)

시연장처럼 시간이 없을 때 쓴다. 시연테스트 지도(`map_1002_150946`)의 ∩ 레일을 **홈 기준
모양(도장)** 으로 떠 두었다(`VICA_Supervisor/ros2/rail_templates/demo_cap.json`). 장소는 넣지 않는다
(장소는 2절대로 앱에서 찍는다).

**홈 기준(2026-10-12 사용자 결정): 홈 = 홈 쪽 꼭짓점에서 옆 0.30 m · 뒤 0.30 m.** 레일은 홈 뒤
0.3 ~ 앞 4.6 m, 홈 왼쪽 0.3~2.54 m 에 놓이는 11.2 m 이고, 홈 ↔ 가장 가까운 레일 점은 0.49 m 다(레일
올라타기 문턱 0.8 m 안이라 출발하자마자 레일을 탄다 — 직전 주행이 레일에서 멀리 끝났을 때 쓰는 복귀 문턱
0.5 m 에도 안이다). 둘레 3.8 × 6.5 m 가 비어 있어야 하는데, 홈
기준으로 **뒤 1.10 m · 오른쪽 0.48 m** 까지 들어간다 → **홈은 뒤쪽 벽에서 1.1 m 넘게 띄워 찍는다**(레일 벽 여유만 보면 1.0 m, 시연 구역까지 1.1 m).
옛 기준(홈 왼쪽 0.5 · 앞 0)은 10-10 연습장 레일만 0.5 m 옮기고 홈은 안 옮긴 흔적이었다(홈 ↔ 레일
0.80 m 로 문턱 경계). 레일테스트 지도(`map_1012_095323`)에서 이 배치로 시험했다.

**코너(2026-10-12): 두 코너 모두 R 1.0.** 짧은 변을 나눠 쓰는 두 코너도 깎기 전 변 길이의 45 % 씩
쓴다(`route_graph_build.fillet_corners`). 전에는 먼저 찍힌 코너가 R 1.0, 다음 코너가 남은 길이의
45 %(R 0.56)를 받아 연습장 실측에서 먼 코너가 직진 속도의 62~65 % 로 감속했다. 앱 레일 편집도 같은
코드라, 이미 저장된 레일은 다시 저장할 때 같은 규칙으로 바뀐다.

**Nav2 를 새 지도로 띄우기 전에 넣는다.** Nav2 launch 는 기동 때 레일 파일이 있어야
route_server 와 레일 트리를 띄운다. 레일 없이 먼저 띄웠으면 넣은 뒤 Nav2 를 다시 띄운다.

1. 앱에서 이 지도의 **홈을 먼저** 찍는다(방향 포함). 정렬해서 저장한 지도면 홈 방향을
   벽과 나란히. 도구가 90° 배수에서 10° 안이면 그 배수로 맞춘다.
2. 젯슨에서 ROS 환경을 불러온 셸(`humble` 별칭)로 미리보기:
   ```bash
   cd ~/VICA-smarthandle/VICA_Supervisor/ros2
   python3 rail_template.py apply --map <지도id>
   ```
   꼭짓점 4개, "레일 11.2 m · 노드 20개 · 코너 R 1.00 · 1.00 — 원본과 같음", 시연 구역 벽·장애물 칸 수, 홈 둘레
   여유(0.62 m 이상)를 본다. 막히면 "멈춤: …"과 막힌 곳 좌표가 나온다 → 홈을 옮겨 다시.
   레일 선이 벽을 지나면 `--force` 로도 넣지 않는다. 레일이 금지구역을 지나면 멈춘다(금지구역은
   길 찾기 지도에서 벽이라 레일 앞 검사가 늘 막힘으로 본다).
   심사석 때문에 레일을 홈 **오른쪽**에 깔아야 하면 `--mirror`.
3. 괜찮으면 `--save` 를 붙여 다시 실행한다. 레일 노드(앱 쪽 supervisor 의 레일 서비스)로 앱과 같은
   길로 저장하고, 지금 주행 지도면 바로 적용한다. 레일 노드가 없거나 ROS 환경을 안 불렀으면
   원인을 말하고 아무것도 쓰지 않는다. 노드 없이 파일만 쓰려면 `--save` 대신 `--offline`.
   - 끝 코드 0 = 저장·적용 끝. 3 = 저장됐지만 아직 적용 안 됨 — 안내 문장을 따른다
     (`no_route_server` 면 Nav2 다시 띄우기, `not_current_map` 이면 이 지도로 Nav2 를 띄울 때 읽음).
     4 = 검사에서 멈춤, 1 = 실패, 2 = 명령을 잘못 씀.
   - `--save` 는 레일 노드가 스케치를 다시 다듬어 저장한다. 그래서 둥글리기 코드를 고친 뒤에는
     supervisor 를 다시 켜야 노드도 새 코드를 쓴다. 도구는 저장 전에 노드에게 미리보기만 받아 비교하고,
     다르면 "다른 레일을 만듭니다 … 저장하지 않았습니다" 와 함께 1 로 끝난다(아무것도 안 바뀜). →
     **로봇이 서 있을 때** supervisor 를 다시 켜고(앱 비상정지 통로 rosbridge 도 함께 다시 켜진다) 다시 저장.
4. 앱 레일 칸을 열어 그림을 확인한다.

**크기 버전 바꿔 끼우기 (2026-10-11 추가).** 시연장 빈 곳이 더 넓으면 공간을 최대로 쓴다. 같은
∩ 모양을 시연 구역 크기에 맞게 늘인 도장이 넷 있다. 늘릴 때 홈 쪽(왼쪽 레일·위 변)은 그대로 두고
반대쪽 레일과 아래 끝만 밀었다 — 어느 버전이든 홈 자리가 같다(홈 쪽 꼭짓점은 늘 옆 0.30 · 뒤 0.30).

| 3.8 × 6.5 m (기본) | `demo_cap` | 2.24 × 4.90 m | 11.2 m | 1.00 · 1.00 | 뒤 1.10 ~ 앞 5.40 · 오른쪽 0.48 ~ 왼쪽 3.32 |

- 미리보기에 "레일 벽 여유 최소 … m — 레일 규칙 0.70 m 통과/미달"이 나온다.
- 연습장처럼 좁은 방에서 시연 구역 가장자리만 벽에 걸리고 레일 벽 여유가 0.70 m 를 지키면
  `--ignore-zone` 을 붙인다 — 시연 구역 검사만 빼고, 레일 벽 여유 0.70 m·금지구역·홈 둘레는 계속 본다.
  `--force` 는 그것까지 다 넘기므로 쓰지 않는다. **시연장에서 멈추면 `--ignore-zone` 대신 홈을 벽에서
  떼어 다시 찍는다**(구역은 홈 기준이라 넓은 방도 홈이 벽에 붙으면 걸린다).
- 연습장(시연테스트 지도)은 10-12 부터 홈 기준이 아니라 **사방 금지구역의 가운데에 4 × 7 레일**을
  깔아 쓴다(사용자 결정, 홈 무관). 그래서 연습장은 도장을 뜨는 원본이 아니다.
- 장소는 버전을 따라 바뀌지 않는다. 폭 4 m 버전이면 오른쪽 레일이 0.2 m 바깥으로 가서 창구와
  대기 자리가 레일에서 그만큼 떨어진다(장소는 앱에서 따로 고친다).
- **도장 원본은 `rail_templates/demo_cap.json` 이다. 연습장에서 다시 뜨지 않는다** — 연습장 레일은 새 홈
  기준이 아니다. 도구도 새 기준 도장(`demo_cap` 과 늘린 버전)은 `extract … --overwrite` 로 덮지 않고 거부한다
  (다른 `--name` 만 된다). 모양을 바꿀 때는 `demo_cap.json` 의
  꼭짓점·구역을 고치고 요약(`source.summary`)을 빈 지도 계산(`free_space_summary`)으로 다시 적은 뒤,
  `make --zone … --overwrite` 로 버전 셋을 다시 만든다. 시험 `test_real_templates_follow_the_home_standard`
  가 홈 기준·요약이 어긋나면 잡는다. 다른 지도 레일을 새 도장으로 뜰 때는 `extract --map <지도> --name <새 이름>`.

확인 기록: 10-10 복지관 지도 미리보기 통과(좌우 뒤집으면 벽 220칸으로 멈춤), 격리 시험 노드로 저장
3경우(새 레일·덮어쓰기+백업·route_server 없음), 레일 노드·ROS 환경이 없으면 파일 0개로 실패.
10-12 오전 레일테스트 지도에서 3.8 × 6.5 → 4 × 6.5 → 4 × 7 을 바꿔 끼우며 주행 — 모두 잘 깔리고 주행 경로
정상(사용자). 그때는 옛 둥글기(먼 코너 R 0.56 · 0.65)였고, 4 × 7 만 새 홈 기준 배치였다.

## 2. 목적지 등록 (앱 — 이름 + 지도 클릭만)

앱 지도 설정 '장소 저장'에서 목적지마다 **지도 찍기 → 입구 방향(지도 그림 기준 4방향)
→ 이름 넣고 저장**. 저장 직후 "대기 장소도 지정할까요?"가 뜬다 — 사용자가 "기다려 줘"
하면 로봇이 혼자 비켜 가 기다릴 자리다. 진입로를 막지 않는 자리에 찍거나 '지정하지
않기'(그 자리에서 대기). 별칭·유형은 이 단계에서 대충 두거나 비워도 된다. 여기서 얻는
것은 **좌표(x·y)·입구 방향(`door_yaw`, `pose.yaw` 도 같은 값)·대기 장소(`wait_spot`)와
UUID** 다. 대기 장소를 찍었으면 '대기 장소로 가보기'로 들어가는 모습을 한 번 확인한다.

**등록 순서가 중요하다** — STT 귀띔은 200자에서 잘리고 별칭은 **먼저 등록한
목적지 것부터** 살아남는다. 사람 이름이 STT 가 제일 못 알아듣는 단어이므로
**교수님 이름이 붙을 접수처를 먼저** 등록한다.

권장 순서: 내과 접수처 → 가정의학과 접수처 → 원무과 → 물리치료실 → 화장실 → 정문
→ (접근 불가 시연용) 수술실

이름 짓기: 서로 안 닮게. "화장실2" 류 형제 이름 금지("화장실 → 화장실2" 오배송의
토대였다). "내과"는 STT 가 "안과"로 적기 쉬우니 대사에서는 교수님 이름·증상으로
부르는 컷을 쓴다(4절).

## 3. 파일 손질 (손 — 글자 전부)

파일: `~/vica_data/destinations/<지도id>/destinations.yaml`

들여쓰기 2칸, `yaw` 는 도(deg) 단위 그대로, 한글은 그냥 쓴다. **`id` 와 `pose` 는
건드리지 않는다.**

| 이름 | `category2` | `aliases` (용건 · 사람 · 증상) |
| --- | --- | --- |
| 내과 접수처 | `reception` | 내과, 김OO 교수님, 김OO 선생님, 배가 아파요, 소화가 안 돼요, 감기 |
| 가정의학과 접수처 | `reception` | 가정의학과, 이OO 교수님, 이OO 선생님, 건강검진, 예방접종 |
| 원무과 | `admin_office` | 수납, 계산, 접수, 진료비, 영수증, 진료 접수 |
| 물리치료실 | `other` | 물리치료, 재활, 도수치료, 허리가 아파요, 무릎이 아파요 |
| 화장실 | `restroom` | 화장실, 볼일 |
| 정문 | `entrance` | 정문, 입구, 나가는 곳, 출구 |
| 수술실 | `other` | 수술실 — 그리고 `is_approachable: false`, `unavailable_reason: 수술실은 관계자 외 출입 금지 구역이라 안내할 수 없습니다.` |

- 별칭은 **사람이 실제로 말하는 문장 꼴**("배가 아파요")이 LLM 매칭이 잘 된다.
- 별칭 총 25개 이내면 STT 귀띔 200자에 다 들어간다.
- `confirm_prompt:`·`arrival_message:` 는 **비워 둔다**(`''`). 10-07부터 앱이 빈 값으로
  저장한다(예전 앱은 받침과 무관하게 "OO으로"를 박았다). 비어 있으면 확인 질문은 음성이
  "OO로/으로 안내해드릴까요?"로, 도착 말은 미션이 "OO에 도착했습니다."로 채운다. 입구
  방향이 있으면 바로 이어 "OO은/는 오른쪽에 있습니다."가 붙는다. 특별한 문장이 필요할
  때만 손으로 적는다.
- `door_yaw`·`wait_spot` 은 앱이 쓴 값을 손대지 않는다(`wait_spot.side` 의 오른쪽·왼쪽은
  앱이 입구 방향 기준으로 계산했고, 로봇은 그 글자를 그대로 말한다).

유형이 도착 뒤 대화를 정한다.

| `category2` | 도착 뒤 질문 | "그래" |
| --- | --- | --- |
| `admin_office` · `reception` · `other` | "여기서 대기할까요?" | "몇 분쯤 걸리실까요?" → 시간 대기 |
| `restroom` | "다녀오시는 동안 여기서 기다릴까요?" | 30분 대기 |
| `entrance` | "여기까지 안내를 마칠까요?" | "안내를 종료합니다." + 홈 복귀 |

## 4. 반영 — 노드마다 읽는 시점이 다르다

| 노드 | 언제 읽나 | 할 일 |
| --- | --- | --- |
| 미션 | 시작 때 + reload 서비스 | `/vica/mission/reload_destinations` 호출 또는 재시작. launch 인자 `map_id:=<지도id>` |
| 음성 LLM (`vica_llm`) | 파일 수정 시각을 보고 **자동** | launch 인자 `map_id:=<지도id>` |
| 웨이크워드(STT 귀띔) · TTS 워밍업 | **시작 때 한 번만** | 음성 launch(⑫ 칸 `ros2 launch launch/vica_voice.launch.py map_id:=$VICA_MAP_ID`) 재시작. 경로는 launch 인자 `map_id` 로 정해진다 |
| 앱 | `/location_list` | 화면 새로고침 |

**`.env` 에 `VICA_DESTINATIONS_YAML` 을 넣지 않는다**(2026-10-11 코드 확인으로 고침 — 예전엔 넣으라고 적혀 있었다).
이 값은 launch 인자보다 먼저 쓰이는데, `.env` 는 웨이크워드 노드만 읽는다(`ros_wakeword_node.py` 37줄
`load_dotenv`). 그래서 지도를 바꾸면 **귀(STT 귀띔)만 옛 지도 목록에 묶이고** LLM·TTS 는 새 지도를 본다.
셸에서 export 하면 귀와 TTS 가 둘 다 묶인다. 지도 바꾸기는 `map_id` 하나로만 한다.

"여기가 어디야?" 답을 원하면 미션 launch 에 `current_building:="OO병원" current_floor:=1`.
지금은 비어 있어 "모릅니다"가 나온다.

앱에서 그 목적지를 고쳐 다시 저장해도 **이름이 같으면 멘트는 지킨다**(별칭은 파일
값을 불러와 그대로 저장). 좌표·입구 방향은 '선택 장소 수정'에서 지도부터 고친다.
**옛 버전 앱으로는 저장하지 않는다** — 입구 방향·대기 장소가 지워진다.

## 6. 대사표 (실제 나오는 말)

**① 수납** — "비카야"/"네?" → "나 수납해야 해"/"원무과로 안내해드릴까요?" → "그래"/"원무과로
안내를 시작합니다." → 도착/"원무과에 도착했습니다. 원무과는 오른쪽에 있습니다. 여기서
대기할까요?" → "그래"/"몇 분쯤 걸리실까요?" → "한 5분"/(대기 장소 있음) "5분 동안 입구
오른쪽에서 기다리겠습니다. 돌아오시면 '비카야'라고 불러 주세요." · (없음) "5분
대기하겠습니다. 돌아오시면 '비카야'라고 불러 주세요."

**② 교수님** — "김OO 교수님한테 가자"/"내과 접수처로 안내해드릴까요?" → "그래"/"내과
접수처로 안내를 시작합니다." → 도착/"내과 접수처에 도착했습니다. 여기서 대기할까요?" →
"아니"/"안내를 종료합니다." → 홈으로.

**③ 증상** — "허리가 너무 아파"/"물리치료실로 안내해드릴까요?" → "그래"/"물리치료실로
